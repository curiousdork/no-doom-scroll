# README

The `kvs` executable supports the following command line arguments:

`kvs set <KEY> <VALUE>`

Set the value of a string key to a string

`kvs get <KEY>`

Get the string value of a given string key

`kvs rm <KEY>`

Remove a given key

`kvs -V`

Print the version

`kvs ls`

Retrieve all keys

`kvs -h` or `kvs help`

Prints help
